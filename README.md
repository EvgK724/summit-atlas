# SUMMIT — выше восьми тысяч

Русскоязычный интерактивный атлас 14 самостоятельных восьмитысячников: 10 вершин Гималаев и 4 Каракорума.

**Открыть:** https://evgk724.github.io/summit-atlas/

## Возможности

- Тёмная тема с неоновой подсветкой и оригинальной иконкой.
- Учебные силуэты всех 14 гор, обзорная карта и сравнение высот.
- Даты первых восхождений, отличительные особенности и ссылки на источники.
- Три размера текста; по умолчанию крупный. Адаптация к iPhone и iPad.
- 42 карточки активного воспроизведения: названия, высоты, география. Ответ сначала скрыт.
- Самооценка «Повторить» / «Вспомнил» / «Легко» назначает интервал. Нет экзамена или баллов.
- Настройки и история повторений сохраняются локально в браузере, без регистрации и синхронизации между устройствами.
- QR-код встроен в приложение. `docs/SUMMIT.html` — автономная копия для офлайн-чтения; внешним источникам нужен интернет.

## Данные и иллюстрации

Исследовательский набор и источники: `sources.json`, сверка 10 октября 2026. Высоты — выбранные справочные значения, не единая новая геодезическая съёмка. Известные расхождения указаны в карточках. Первое восхождение на Чо-Ойю датировано 19 октября 1954; у Канченджанги сохранено пояснение о непосещении самой высшей точки в 1955 году.

Рисунки — авторские условные силуэты, не точные профили и не маршруты восхождения. Координаты округлены для обзорной карты. Карта не изображает политические границы. Ассоциации созданы для обучения и не выдаются за этимологию.

## Сборка

Нужен Python 3; дополнительные пакеты не требуются. Все браузерные скрипты, стили и рисунки встроены в HTML.

```sh
node tests/learning.cjs
python3 scripts/build.py
python3 -m http.server 8766 --directory docs
```

Откройте http://localhost:8766. GitHub Pages публикует ветку `main`, каталог `/docs`.

Исходники: `src/`. Чистая логика карточек и интервалов: `src/learning.js`. QR, иконки и манифест: `docs/assets/`, `docs/site.webmanifest`. В приложении нет аналитики, сторонних скриптов и сетевой отправки прогресса.

## Добавить на экран «Домой»

Откройте опубликованное приложение в Safari на iPhone или iPad, нажмите «Поделиться» → «На экран „Домой“». Иконка и название подготовлены в метаданных приложения. Сайт не устанавливает себя автоматически; для гарантированного офлайн-чтения скачайте HTML в разделе «Об атласе».
